## 🚀 Overview

CryptoSphere is a **React-based cryptocurrency tracking web application** that displays real-time prices and market data.

It integrates live data from external APIs to provide accurate and up-to-date crypto insights with a clean and responsive UI.

---

## ✨ Features

- 🪙 Real-time cryptocurrency price tracking  
- 📊 Live market data (via CoinGecko API)  
- ⚡ Fast and responsive UI  
- 📱 Mobile-friendly design  
- 🔄 Dynamic data updates using React Hooks

## 📡 API Integration

- 🔗 CoinGecko API for real-time crypto data  
- Fetching live prices and market stats  
- Async data handling using `fetch` / `axios`  

---

## 🧠 How It Works

1. App loads → React components initialize  
2. API call made to CoinGecko  
3. Data fetched asynchronously  
4. State updated using React Hooks  
5. UI re-renders with latest data
